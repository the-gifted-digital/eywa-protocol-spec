# Brand Assets — Raw Sources

Per DR-029 + Bible Part 31. Raw binary brand sources (logos, photography, illustrations, icons). Web-ready processed versions go in respective subfolders. Hosting/CDN delivery handled by theme/ implementation per stack.

## Folder map

- `logos/` — Brand logo variants (primary, monochrome, light/dark, favicon)
- `photography/` — Photography (raw originals + processed web-ready + consent records)
- `illustrations/` — Illustration sources + processed SVG/PNG + proprietary diagrams
- `icons/` — Custom icon SVGs (when default icon library doesn't cover brand needs)

See `design/brand-foundation/imagery.md` for usage rules + organization conventions.
