## How to use this file

For each Business Goal from `business-context.md` Section 1:
1. List the brand promise(s) involved (from `eywa-dna-graph.md` Fields 3, 4, 7)
2. Identify which TRUST pillar(s) serve (from `eywa-trust-rubric.md`)
3. Choose the SEO tactic (one or many)
4. Map to a content cluster (will appear in Phase E sitemap)
5. Define the success metric (becomes input to EYWA Compound Growth dashboard)

Every row should answer: **"If this row succeeds, which business goal moves?"**

If a row doesn't trace to a business goal → cut it. If a business goal has no row → flag as gap.

## Phase E Sitemap Justification Rule

> **Hard rule (per Bible Part 30.7):** Every page that enters the sitemap in Phase E must trace to a row in this alignment map. If a proposed page doesn't trace → cut or revise alignment map first.

This rule prevents "SEO-only" pages that have keyword interest but no business or brand justification.

## Phase F Content Brief Integration

When writing content briefs (per DR-017), each brief MUST cite:
- `alignment_map_row_id` — which row this content piece serves
- `brand_promise` — Field 3/4/7 reference
- `trust_pillar` — which pillar progression this advances
- `success_metric` — which metric this content piece will move

Without these fields → content brief is rejected.
