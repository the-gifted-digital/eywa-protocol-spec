## Part 3 — EYWA Journey Map (McKinsey CDJ adapted)

> Per Bible §30.11.2. 5-stage patient lifecycle from awareness to advocate. Per stage: triggers + touchpoints + content needs.

### Stage 1 — Initial Consideration
**Patient state:** "I notice something is off / I heard about X / a doctor mentioned this"

- **Triggers:** {what makes patient enter this stage}
- **Touchpoints:** {Google search / Pantip thread / friend talk / doctor referral / podcast / etc.}
- **Content needs:**
  - {Educational pillar — e.g., "Why ED happens"}
  - {Awareness explainer — e.g., "Vascular link to ED"}
- **EYWA Content Template fit:** {T1 medical-condition / T6 concept explainer / T-knowledge}

### Stage 2 — Active Evaluation
**Patient state:** "I'm comparing 2-3 options. Who do I trust?"

- **Triggers:** {what moves patient into active evaluation}
- **Touchpoints:** {clinic websites / Google Maps reviews / Facebook posts / doctor profiles / Pantip comparison threads}
- **Content needs:**
  - Credentials page (T9 doctor profile)
  - Treatment comparison content
  - Pricing transparency
  - Real outcome evidence
- **EYWA Content Template fit:** {T2 service page / T9 doctor profile / T17 case study / T19 pricing}

### Stage 3 — Moment of Purchase
**Patient state:** "I'm ready to book. Make it easy."

- **Triggers:** {form filled / LINE Add Friend / phone call}
- **Touchpoints:** {booking form / branch info page / response speed / first-visit prep}
- **Content needs:**
  - Booking CTA + form clarity
  - Branch info (address, hours, parking, transit)
  - FAQ on first visit
  - What to bring
- **EYWA Content Template fit:** {T10 branch landing / T-ADS-2 booking LP if from ads}

### Stage 4 — Post-Purchase
**Patient state:** "Treatment started. Did I make the right choice?"

- **Triggers:** {first visit done / treatment phase 1 / first follow-up}
- **Touchpoints:** {follow-up calls / LINE messages / treatment tracking / aftercare content}
- **Content needs:**
  - Aftercare guides
  - Progress tracking explanations
  - What to expect at each phase
  - When to call the clinic vs wait
- **EYWA Content Template fit:** {T6a aftercare / T11 patient guide}

### Stage 5 — Loyalty Loop
**Patient state:** "I'm a fan. I'll refer + come back."

- **Triggers:** {outcomes achieved / referring friend / maintenance care need}
- **Touchpoints:** {periodic check-ins / alumni community / referral program / email newsletter}
- **Content needs:**
  - Maintenance content
  - Success stories (consented)
  - Referral mechanism
  - Member-only benefits if applicable
- **EYWA Content Template fit:** {T17 case study (consented) / T-newsletter / referral landing}
