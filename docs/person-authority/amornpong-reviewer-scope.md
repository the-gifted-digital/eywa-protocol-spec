## สถานะ (2026-10-31)

- Operator: ขอบเขตวิชาชีพของแพทย์ครอบคลุมเนื้อหาในเครือ ณ ตอนนี้ — จะ re-review matrix นี้กับแพทย์อีกรอบก่อนบันทึก `seo_reviewer_scope`
- Cluster ที่เสนอเป็น co_review: เลือก **ปรับเนื้อหาให้อยู่ในขอบเขตทันตกรรม** แล้วเปลี่ยนเป็น primary (ไม่ขยาย scope ตามเนื้อหา — DR-083 ข้อ 2)

## หลักที่ใช้เสนอ

- **primary** = อยู่ในบอร์ดหรือการฝึกอบรมเฉพาะทางที่บันทึกไว้ (OMFS, Orthodontics, Dental Sleep Medicine, Implantology, Craniofacial) หรืออยู่ในขอบเขตใบอนุญาตทันตกรรมทั่วไป
- **co_review** = เนื้อหาที่กล่าวอ้างผลต่อระบบอื่นของร่างกาย (สมอง, ระบบทั้งร่างกาย, longevity, performance) ต้องมีแพทย์ (แพทยสภา) ร่วม review
- **excluded** = ไม่มีในชุดนี้

## ผลกระทบที่ต้องรู้ก่อนอนุมัติ

- **7 cluster ที่เป็น co_review (106 หน้า)** จะยังแสดงชื่อแพทย์เป็น reviewer ไม่ได้จนกว่า VTH จะมีแพทย์ร่วม review เพราะตอนนี้แบรนด์มี reviewer คนเดียว ทางเลือกคือ (ก) หาแพทย์ร่วม (ข) แก้เนื้อหาให้อยู่ในขอบเขตทันตกรรม แล้วเปลี่ยนเป็น primary
- **cross-cutting + vth-signature (171 หน้า)** ต้องตัดสินรายหน้า เพราะ cluster ไม่ได้บอกว่าเนื้อหาอยู่ในขอบเขตไหน
- approved จริงตอนนี้ 54 จาก 688 — ระดับ scope ไม่ได้แทนการ review จริง หน้าที่ยังไม่ approved ยังไม่ควรมี `reviewedBy`
